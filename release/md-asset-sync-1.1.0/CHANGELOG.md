# 更新记录

## 1.1.0

- 新增插件语言设置，支持 English 和简体中文，默认 English。
- 命令、设置、弹窗、进度提示、通知和开发者控制台日志随插件语言切换。
- 默认 README 改为英文，并新增独立中文说明。

## 1.0.0

- 首次发布。
- 从外部 Markdown 的原始磁盘目录解析相对和绝对本地图片路径。
- Markdown 目标目录由用户选择，图片目录遵循 Obsidian 原生附件设置。
- 支持批量导入和中英文文件名及路径。
- 同名附件先比较 MD5，内容一致时复用。
- 内容不同时支持追加 MD5、覆盖和跳过三种策略。
- 支持保留或移除找不到的本地图片链接。
